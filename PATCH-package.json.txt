Do package.json do sekcie "scripts" doplň tieto riadky.

Ak už máš vlastný refresh súbor, uprav cestu pri "refresh-cache" podľa reálneho názvu súboru.

Príklad:

{
  "scripts": {
    "start": "node server.js",
    "refresh-cache": "node scripts/refresh-cache.js",
    "repair-filmbaze-streams": "node scripts/filmbaze-stream-repair.js",
    "refresh-cache-with-repair": "node scripts/refresh-cache-with-repair.js"
  }
}

Ak scripts/refresh-cache.js v tvojom projekte neexistuje, použi názov súboru, ktorý tam reálne máš, napríklad:

"refresh-cache": "node scripts/update-cache.js"

alebo:

"refresh-cache": "node update-cache.js"
