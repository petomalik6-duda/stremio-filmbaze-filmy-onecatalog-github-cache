VOLITELNE, ale odporucane pre stream fallback v server.js
=======================================================

1) Na zaciatok server.js pridaj:

import { createRequire } from "module";
const require = createRequire(import.meta.url);
const { buildFilmbazeTitleVariants } = require("./scripts/filmbaze-title-normalizer.cjs");

Ak server.js uz pouziva require(), pouzi len:

const { buildFilmbazeTitleVariants } = require("./scripts/filmbaze-title-normalizer.cjs");

2) V stream route, ked povodna logika nenajde stream, pridaj fallback:

if (!streams || streams.length === 0) {
  const variants = buildFilmbazeTitleVariants(movie);

  for (const q of variants) {
    console.log("[filmbaze title fallback] trying:", q);

    // Pouzi existujucu funkciu addonu, ktora uz vie hladat streamy podla nazvu.
    // Nazov tejto funkcie sa v tvojom addone moze volat inak.
    const found = await searchStreamsByTitle(q, movie.year);

    if (found && found.length) {
      streams = found;
      break;
    }
  }
}

Dolezite:
- Nepovazuj primaryVideo:null za chybu. Niektore filmy funguju aj tak.
- Fallback sa ma spustit az vtedy, ked stream route nenasla ziaden stream.
