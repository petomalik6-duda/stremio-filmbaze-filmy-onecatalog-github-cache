V refresh/enrich logike nájdi pravidlo, ktoré preskakuje už skontrolované položky.

Zlé pravidlo býva napríklad:

  if (item.detailChecked) return item;

alebo:

  if (existing?.detailChecked) continue;

Nahraď ho pravidlom:

  if (item.detailChecked && item.primaryVideo) return item;

alebo:

  if (existing?.detailChecked && existing?.primaryVideo) continue;

Dôležité:
Položka s `detailChecked: true` a `primaryVideo: null` NIE JE hotová.
Musí sa skúšať znova pri ďalšom refreshi.
