Do package.json vlož do "scripts" toto:

{
  "scripts": {
    "start": "node server.js",
    "refresh-cache": "node scripts/refresh-cache.js",
    "repair-filmbaze-streams": "node scripts/filmbaze-stream-repair.js",
    "refresh-cache-with-repair": "node scripts/refresh-cache-with-repair.js"
  }
}

POZOR:
Ak už máš v package.json scripts, nevkladaj celý blok duplicitne.
Len doplň chýbajúce riadky.

Ak súbor scripts/refresh-cache.js neexistuje, nájdi pôvodný cache script a uprav riadok napríklad takto:

"refresh-cache": "node scripts/update-cache.js"

alebo:

"refresh-cache": "node update-cache.js"
