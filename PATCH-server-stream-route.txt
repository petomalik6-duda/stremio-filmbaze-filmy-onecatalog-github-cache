PATCH PRE FILMBÁZE STREAM ROUTE
==============================

Cieľ:
Keď film nemá primaryVideo alebo bežný fallback nič nenájde, skúsiť viac názvových variantov.
Toto je dôležité pre názvy ako:
- Barvy zla: Černá
- Kolory zła: Czerń

1) Nahraj súbor:

scripts/filmbaze-title-normalizer.cjs

2) V server.js alebo v súbore, kde máš /stream route, pridaj import.

Ak je server.js CommonJS:

const { buildFilmbazeSearchVariants } = require('./scripts/filmbaze-title-normalizer.cjs');

Ak má projekt "type": "module" a používa import:

import { createRequire } from 'module';
const require = createRequire(import.meta.url);
const { buildFilmbazeSearchVariants } = require('./scripts/filmbaze-title-normalizer.cjs');

3) V /stream route nájdi miesto, kde sa hľadá stream a keď nič nenájde, vráti sa:

return res.json({ streams: [] });

Pred tento return vlož fallback podobný tomuto:

const variants = buildFilmbazeSearchVariants(movie);
console.log('[filmbaze fallback] variants for', movie.name, variants);

for (const q of variants) {
  try {
    console.log('[filmbaze fallback] trying:', q);

    // TU POUŽI TVOJU EXISTUJÚCU FUNKCIU, ktorú už stream route používa pri Mortal Kombat 2.
    // Príklady názvov môžu byť iné v tvojom projekte:
    // const found = await searchStreamsByTitle(q, movie.year);
    // const found = await findStreams(q, movie.year);
    // const found = await searchFilmbazeStreams(q, movie.year);

    const found = await searchStreamsByTitle(q, movie.year);

    if (found && found.length) {
      console.log('[filmbaze fallback] found streams using:', q, found.length);
      return res.json({ streams: found });
    }
  } catch (err) {
    console.warn('[filmbaze fallback] failed for', q, err.message);
  }
}

4) Ak tvoja existujúca funkcia nemá názov searchStreamsByTitle, nahraď tento riadok:

const found = await searchStreamsByTitle(q, movie.year);

názvom funkcie, ktorá už dnes funguje pre filmy ako Mortal Kombat 2.

5) Test variantov lokálne:

node scripts/test-title-variants.cjs "Barvy zla: Černá" "Kolory zła: Czerń" 2026
