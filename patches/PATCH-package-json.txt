V package.json odporúčam mať tieto scripts:

{
  "scripts": {
    "start": "node server.js",
    "refresh": "node scripts/refresh.js",
    "refresh-cache": "node scripts/refresh.js",
    "repair-imdbid": "node scripts/filmbaze-imdbid-repair.cjs"
  }
}

Dôležité: pôvodný script "refresh" už v tvojom projekte existuje. Nový "refresh-cache" je len alias, aby sa v budúcnosti workflow nemýlil.
