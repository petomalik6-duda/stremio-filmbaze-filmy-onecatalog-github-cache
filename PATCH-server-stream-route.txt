Optional server.js improvement:

The cache repair fills imdbId from tmdbId. If your stream route currently searches only by primaryVideo or name,
add imdbId as the first fallback key.

Pseudo-code:

let streams = [];

if (movie.primaryVideo) {
  streams = await getStreamsFromPrimaryVideo(movie.primaryVideo);
}

if ((!streams || streams.length === 0) && movie.imdbId) {
  console.log('[filmbaze stream] fallback by imdbId:', movie.imdbId);
  streams = await searchStreamsByImdbId(movie.imdbId);
}

if (!streams || streams.length === 0) {
  // keep your existing title fallback here
}

return { streams };

Do not treat primaryVideo:null as a fatal error. Mortal Kombat II proves that primaryVideo:null can still work when imdbId exists.
